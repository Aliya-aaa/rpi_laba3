# Учебная платформа «Знание»

Онлайн-платформа для подбора преподавателей и записи на индивидуальные занятия. Проект реализован на React с использованием react-router-dom для маршрутизации

## Описание

Платформа предоставляет:

- Каталог из 10 преподавателей с подробной информацией
- Детальные страницы каждого лектора с программами курсов и тарифами
- Поиск и фильтрацию по имени и предметам
- Адаптивную вёрстку для мобильных устройств

## Стек технологий

- **React** 18.2.0
- **Vite** 5.0.0 (сборщик)
- **react-router-dom** 6.x (маршрутизация)
- **CSS3** (без UI-библиотек, согласно ТЗ)

## Требования

- Node.js версии 18 или выше
- npm версии 9 или выше

Проверить версии:

``node -v``

`` npm -v``

## Установка и запуск

### 1. Клонировать репозиторий

``git clone https://github.com/твой-username/rpi_laba3.git``

``cd rpi_laba3``

### 2. Установить зависимости

``npm install``

### 3. Запустить dev-сервер

``npm run dev``
